# Doorways · exercises, draft 2

One exercise per emotion, a mix of kinds, picked for what suits each feeling:
**move** (body) · **make** (drawing, paper, colour, photos; no skill needed) · **notice** (senses, surroundings) · **write** · **reach out** (a person) · **do** (one small action).
Mix: make 17, move 10, reach out 6, do 6, notice 5, write 4.
Heavy feelings (sadness, grief, shame, numbness, hurt) stay with the feeling instead of trying to fix it.
`timer` = optional ring in seconds. Edit freely; nothing is built yet.
